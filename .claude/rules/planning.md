# 작업 계획 및 진행 관리 규칙

## 계획 파일 구조

작업 규모가 크거나 여러 도메인에 걸친 경우, 프로젝트의 `.claude/plan/` 디렉토리에 계획을 관리한다.

```
.claude/plan/
├── plan.md          # 전체 계획 요약 및 진행 현황
└── tasks/
    ├── 01-<도메인>.md
    ├── 02-<도메인>.md
    └── ...
```

## plan.md 형식

- 도메인별 작업 파일 링크 테이블 포함 (경로: `./tasks/`)
- 각 도메인의 완료 상태를 `완료 (n/n)` / `부분 완료 (n/n)` 형식으로 표시
- 완료 항목 요약 섹션과 보류 항목 섹션을 분리하여 작성

## task 파일 형식

- 파일 상단에 전체 체크리스트로 진행 현황 한눈에 파악
- 각 항목은 `- [x]` (완료) / `- [ ]` (미완료 또는 보류) 체크박스 사용
- 이모지 사용 금지 — 체크박스만 사용
- 보류 항목에는 **보류 이유**를 명시

## 작업 완료 시

- 해당 task 파일의 체크박스 업데이트
- plan.md의 상태 칸과 완료/보류 요약도 함께 업데이트
